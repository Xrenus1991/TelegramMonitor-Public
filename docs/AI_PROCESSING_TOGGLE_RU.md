# Отключение ИИ-обработки сообщений

В конфигурации процесса анализа установите:

```env
AI_PROCESSING_ENABLED=false
```

Новые вызовы `MessageAnalyzer.analyze_batch` возвращают `None` без вызова ИИ-провайдера. Сбор и сохранение сообщений этим переключателем не отключаются. Для включения задайте `AI_PROCESSING_ENABLED=true` (по умолчанию).

Отключающие значения: `false`, `0`, `no`, `off` (без учёта регистра). Значение читается при каждом вызове, однако изменение окружения Docker обычно требует пересоздания контейнера. Уже начатые запросы не отменяются. Это переключатель конфигурации, не кнопка панели управления.
