# Отключение ИИ-обработки сообщений

В конфигурации процесса анализа установите:

```env
AI_PROCESSING_ENABLED=false
```

После применения конфигурации новые вызовы `MessageAnalyzer.analyze_batch` возвращают `None` **без обращения к ИИ-провайдеру**. Сбор сообщений и сохранение в базу данных этим параметром не отключаются. Для включения установите `AI_PROCESSING_ENABLED=true` (значение по умолчанию).

Поддерживаются значения отключения: `false`, `0`, `no`, `off` (регистр неважен). Значение читается при каждом вызове, но изменение переменной окружения контейнера обычно требует его пересоздания/перезапуска. Ранее запущенный запрос к провайдеру не отменяется. Это конфигурационный переключатель, не кнопка панели управления; управление из UI требует отдельной интеграции с работающим сервисом.
